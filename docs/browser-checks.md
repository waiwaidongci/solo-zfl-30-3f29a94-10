## 发现并在检查过程中修复的问题（真实回归）

1. 全局订阅式重绘会在封存面板操作中途重建 DOM，导致合规检查结果写入脱离文档的节点——改为各写操作后显式局部刷新。
2. 复查观测说明曾被当成对原标记备注的覆盖，差异表出现「备注 疑似横梁→无新增缺损」的语义错误——改为观测单列、仅保存状态参与字段差异。
3. 备份策略原为「写前备份上一版」，封存后立即坏档会丢失封存本身——改为「写后回读校验通过才提升为最近完好备份」。
4. 自查发现只读逃逸：编辑已封存潜次的标记时把所属潜次改挂到未封存潜次即可绕过只读——数据层对原潜次与目标潜次双侧校验封存状态并拒绝（单元测试「只读逃逸防护」覆盖）。
